One funny single-line one-star review from a house cat about its human,
for the [make.fun](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990)
"Make the AI Judge Laugh: Cat Reviews Its Human" bounty.

## Run it

```sh
python3 main.py
# writes /output/entry.txt
```

The program writes a single line, under 200 characters, in the deadpan
shape of a real one-star review: a specific, recognisable complaint
(the laptop keyboard) with a sting in the last few words.
